## 반영한 기반 개선

- 14개 모집요강의 학년도와 PDF·추출 텍스트 SHA-256 등록.
- 다른 학년도 요청과 모호한 상대 연도 재질문, 문서 답변의 학년도 표시.
- 기존 두 질문 범위에서 후속 학년도 유지와 현재 발언의 학년도 수정 우선.
- API 입력 타입·질문 길이 검증, HTTP 400 JSON 오류, 후속 응답 필드 통일.
- 개별 외부 호출 제한시간과 SDK 자동 재시도 제한.
- 개인정보를 담지 않는 요청 메트릭 로그.
- 누락된 `.env.example`과 실제 NER 로딩에 필요했던 `protobuf` 의존성 추가.

## 기존 부분 통과 질문

2026-11-02 평가의 판정이며, 기반 코드 수정만으로 해결됐다고 처리하지 않는다.

1. **건국대 수시 전형 일정**: 주요 공통 일정 외 세부 전형별 고사·발표 일정의 누락을 원본 PDF와 대조한다. 적용 전형과 예외, 시작·마감 시각을 보존한다.
2. **연세대 정시 전형 방법과 제출서류**: 일반전형 일반계열 외 국제·예체능·고른기회의 적용 범위를 분리한다. 지원자 유형과 전형의 예외를 교차 검토한다.
3. **연세대 정시·고려대 수시 경영 비교와 일정**: 대학별 세부 일정을 보강한다. 서로 다른 전형의 점수나 지원자 집단을 직접 비교해 합격 가능성을 단정하지 않는다.
