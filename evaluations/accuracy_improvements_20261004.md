## 1. 결과 요약

이전에는 표를 찾았어도 답변을 보류하거나, 표의 다른 행·열을 섞어 오답을 만들었다. 이번에는 영어 환산표를 코드로 읽고, 원본 PDF에서 확인한 복합 표를 대학·전형·모집단위·단계·적용 조건에 따라 구조화했다.

모델의 독립 검토만으로는 오류를 모두 차단하지 못했다. 중간 평가에서 온라인 제공 동의 조건, 수의예과와 컴공의 최저 기준, 서로 다른 모집 방식의 평가요소를 섞은 주장이 검증을 통과했다. 해당 사례는 원문을 직접 대조한 구조화 자료로 수정했다.

## 3. 코드 변경

- **근거 페이지 보존:** 하나의 근거 ID가 선택된 PDF 한 페이지 전체를 포함한다. 표 제목과 마지막 행이 잘리지 않는다.
- **항목별 답변:** 복합 질문의 각 항목을 별도로 생성·검증하고 미답변 항목을 표시한다.
- **영어 환산표:** 명시된 등급 9개와 점수 9개를 순서대로 읽고 불완전하거나 충돌하는 표를 거부한다.
- **검토된 표 우선:** 미술 전형 3개 기록과 주요 주제 7개 기록을 데이터로 관리한다. 질문 문장과 정답을 짝지은 목록이 아니라 대학·전형·모집단위·주제·적용 조건으로 조회한다.
- **원문 변경 감지:** 각 기록의 출처 페이지 해시를 확인한다. 다중 출처 중 하나라도 변경되면 그 기록을 사용하지 않는다.
- **적용 범위 제한:** 의예과 등 다른 모집단위나 다른 세부 전형에 기존 기록을 자동 적용하지 않는다.
- **후속 문맥:** 학과 수정 시 이전 요청 항목을, 항목 변경 시 이전 학과를 유지한다.
- **추가 검증:** 생성 문장의 의미를 원문과 대조하며 재작성은 최대 한 번이다. 명시된 평가점수 합계가 맞지 않는 문장도 차단한다.

## 4. 평가 방법과 기록

1. `image_questions_improved_20261003.json`: 전체 NER를 포함한 23문항 실행.
2. `image_questions_verified_20261003.json`: 의미 검증을 추가한 중간 실행. 오류가 남았으므로 최종 결과로 사용하지 않는다.
3. `image_questions_final_20261004.json`: 같은 질문의 NER를 재사용하고 **검색·생성·의미 검증을 새로 실행**한 최종 결과. 23건, 예외0건, 외부 호출8회.
4. `image_questions_final_replay_20261004.json`: 마지막 모집단위 인식 수정까지 포함한 코드에 저장된 응답을 재입력. 23건 모두 답변 동일. 외부 API 호출 없음.

자동 테스트 통과율은 실제 정답률이 아니다. 이번 문항은 수정에 사용한 회귀 문항이므로 새 질문의 성능을 추정하는 독립 평가도 아니다. 전체 정답률을 과장하지 않도록 위 표에는 실제 확인한 변화와 미완료 범위를 구분했다. 12번 연도 질문은 이전과 동일하게 주요 채점 범위에서 제외한다.

## 5. 남은 범위

- **경쟁률·충원·합격 백분위·시설:** 공식 입시결과나 캠퍼스 자료가 아직 없으므로 14·15·20·21번의 구체적인 정보 제공은 미완료다.
- **대학 확인:** 22번은 대학명이 없어 확인 질문을 유지한다.
- **전체 전형 범위:** 구조화 자료는 검토한 일부 대학·전형에 한정된다. 미검토 표는 여전히 보류되거나 모델 해석 오류가 발생할 수 있다. 원본 검토 후 자료 확장이 필요하다.
- **출처 응답 규격:** 기존 API의 `location`은 하나의 PDF 경로를 표현한다. 내부에는 여러 대학의 근거가 남지만 API에서 모두 표현하려면 별도 규격 변경이 필요하다. 이번에는 요청 범위에 따라 변경하지 않았다.
