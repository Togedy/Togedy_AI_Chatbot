# 실제 API 대화 문구 검증

검증일: 2026-10-30

- 전체 pytest: 190개 통과.
- 실제 로컬 KoBERT NER: 6개 대화 시나리오, 13개 API 응답의 처리 흐름 통과.
- NER 테스트 대역과 실제 모델의 answer 전체 문구 일치: 13/13.
- 외부 LLM은 호출하지 않았습니다. 이 사례들은 검토된 문서 자료와 정형 안내로 답합니다.
- 앞서 채팅에서 설명용으로 작성한 예시와 실제 출력은 문구가 다릅니다. 문서 답변 본문에는 항목식 나열이 남아 있습니다.
- 실제 모델 검사에서 빈 전형 칸의 괄호 안내를 선택 값으로 추출하는 문제가 확인되어, NER 입력 단계에도 안내 제거를 적용하고 재검증했습니다.

## 실제 모델의 응답 원문

### 대학 보충 후 문서 답변

사용자 입력:

```text
정시 제출서류 알려줘
```

실제 answer 원문:

```text
현재까지 확인한 내용: 대학: 미확인 / 전형: 정시 / 학과·모집단위: 미지정 / 궁금한 내용: 제출서류

대학 정보를 알려주시겠어요? 확인할 모집요강을 정한 뒤 안내해 드릴게요.
```

메타데이터: `{"NER": {"KEYWORD": ["제출서류"], "TYPE": ["정시"], "UNI": []}, "reply": true}`

사용자 입력:

```text
연세대
```

실제 answer 원문:

```text
서류는 본인의 출신 학교와 온라인 제공 동의 여부에 맞춰 확인하는 게 중요해요. 확인된 내용을 함께 볼게요.

연세대 정시
[제출서류]
지원자 유형별 기본 제출서류와 추가서류 안내
- 국내 고교 출신·온라인 제공 동의자: 기본 학생부는 별도 제출 없이 원서접수 시 전산 제공 동의로 대체합니다. 학생부 추가·변경사항이 있으면 학교장 직인 학생부와 수정요청서 등 별도 절차가 적용됩니다.
- 학생부 온라인 제공이 불가능하거나 제공을 신청하지 않은 지원자: 학교장 직인이 날인된 학생부 사본 1부를 원서접수 사이트에 업로드합니다.
- 검정고시·온라인 제공 동의자: 합격증명서 별도 제출을 온라인 제공 동의로 대체합니다. 국내 고교 재학 이력이 있으면 학생부도 업로드해야 합니다.
- 검정고시·온라인 자료 제공 미신청자 등: 검정고시 합격증명서 1부를 업로드합니다. 국내 고교 재학 이력이 있으면 학생부도 필요합니다.
- 외국 소재 고교 출신: 졸업(예정)증명서 1부가 필요합니다. 국내 고교 재학 이력이 있으면 학생부도 업로드합니다.
- 고른기회전형: 연세한마음·농어촌·특성화고교졸업자·특수교육대상자 등 지원자격별 증빙서류가 다릅니다. 해당 자격의 목록을 추가로 확인해야 합니다.
기본 서류 중심의 안내입니다. 지원자격·졸업 시기·자료 변경 여부에 따른 예외와 추가 제출은 원문 PDF 17~18쪽을 확인해야 합니다.
```

메타데이터: `{"NER": {"KEYWORD": ["제출서류"], "TYPE": ["정시"], "UNI": ["연세대"]}, "NER_Page_1": "p17", "NER_Page_2": "p18", "location": "university\\yonsei\\jungsi.pdf", "reply": false}`
