# Togedy AI Chatbot 답변 품질 평가 보고서

> **핵심 요약**
>
> 사용자 질문 23개를 실제 모델로 실행하고, 평가 범위에 해당하는 22개를 채점했다. 완전 정답은 0개, 부분 충족은 3개였다. 주요 문제는 **검색 단계로 연결되지 않는 질문**, **정상 정보도 제외하는 인용 검증**, **검색 없이 생성되는 근거 없는 답변**이다.

## 1. 평가 결론

현재 챗봇은 일부 모집인원과 일정을 확인할 수 있으나, 사용자가 요청한 정보를 끝까지 제공하는 데 실패했다. 특히 확인 가능한 자료가 있어도 답변이 보류되는 경우와, 자료를 검색하지 않은 채 대학별 사실을 추측하는 경우가 함께 나타났다.

따라서 다음 개선에서는 검색 결과 자체의 순위뿐 아니라 **질문을 검색으로 연결하는 조건**과 **생성 후 검증 방식**을 함께 다뤄야 한다.

> **결과 해석 시 주의**
>
> 완전 정답률 0%는 모든 응답 문장이 거짓이라는 뜻이 아니다. 질문의 핵심 요구를 모두 해결한 문항이 없었다는 뜻이다. 답변 보류 17개에는 타당한 보류와 검색·생성 실패가 함께 포함돼 있다.

## 2. 평가 범위와 채점 기준

### 2.1 평가 범위

- 이미지의 번호 하나를 평가 문항 하나로 취급했다.
- 9번의 합격 가능성 비교와 전형일정 질문은 하나의 복합 질문으로 평가했다.
- 12번의 “작년 인원 미달 학교” 질문은 실행하되, 사용자가 정한 연도 질문 제외 범위에 따라 채점 분모에서 제외했다.
- 각 문항은 이전 질문의 대화 상태를 이어받지 않았다.
- 이번 문서는 기존 실행 결과를 정리한 것이며, 추가 모델 호출이나 서비스 코드 수정은 수행하지 않았다.

### 2.2 판정 기준

| 판정 | 기준 |
| --- | --- |
| 완전 정답 | 질문의 핵심 요구와 명시한 모든 대상을 충족하고, 근거 없는 단정이나 자료와의 모순이 없음 |
| 부분 충족 | 검증 가능한 유용한 정보를 일부 제공했으나, 요청 항목 또는 대상 일부가 누락됨 |
| 답변 보류·미해결 | 확인 불가 안내, 단순 거절, 일반적인 확인 권고에 그쳐 핵심 요구가 해결되지 않음 |
| 오답·근거 없는 답변 | 원문과 반대되는 사실을 제시하거나, 질문의 대상을 잘못 해석하거나, 근거 없이 대학별 판단을 생성함 |
| 평가 제외 | 사전에 합의한 지원 범위 밖의 질문 |

대학 선택이나 합격 가능성처럼 단일 정답이 없는 질문은, 근거 없는 우열·합불 예측을 피하면서 질문에 맞는 판단 기준과 필요한 정보를 안내했는지 평가했다. 단순히 답변을 거절한 경우는 해결로 인정하지 않았다.

## 3. 정량 평가 결과

### 3.1 문항별 최종 결과

| 지표 | 문항 수 | 비율 | 해당 문항 |
| --- | ---: | ---: | --- |
| 완전 정답 | 0 | **0.0%** | 없음 |
| 부분 충족 | 3 | **13.6%** | 1, 4, 5 |
| 답변 보류·미해결 | 17 | **77.3%** | 2, 3, 6, 7, 8, 9, 10, 13, 14, 15, 16, 17, 18, 20, 21, 22, 23 |
| 오답·근거 없는 답변 | 2 | **9.1%** | 11, 19 |
| 합계 | **22** | **100.0%** | 12번 제외 |

**계산식**

- 완전 정답률 = 완전 정답 문항 수 ÷ 평가 문항 수 × 100 = 0 ÷ 22 × 100 = **0.0%**
- 일부라도 유효한 정보를 제공한 비율 = (완전 정답 + 부분 충족) ÷ 평가 문항 수 × 100 = 3 ÷ 22 × 100 = **13.6%**

부분 충족 비율은 완전 정답률과 별개의 지표다. 부분 답변이나 답변 보류를 정답에 포함해 점수를 높이지 않았다.

### 3.2 처리 단계별 관찰

| 관찰 항목 | 결과 | 해석 |
| --- | --- | --- |
| 문서 검색 경로 진입 | 평가 대상 22개 중 5개 | 1·2·4·5·9번만 문서 검색으로 연결됨. 검색 정확도 자체를 의미하지는 않음 |
| 실제 LLM 호출 | 총 28회 | 평가 제외 문항을 포함한 23문항 전체 실행 기준 |
| 문서 기반 답변 호출 | 10회 | 여러 대학·전형을 묻는 문항은 호출을 나눠 처리 |
| 문서 기반 생성 주장 | 23개 | 문항 수가 아니라 생성된 주장 수 |
| 인용 검증 통과 주장 | 6개 / 23개, 약 26.1% | 검증 통과율이며, 의미적 정확도나 문항 정답률은 아님 |

## 4. 주요 실패 사례

### 사례 A. 논술 최저기준에 대한 사실 오류 — 11번

**질문**

> 건대 컴공과 논술 최저가 있는 거야? 없는거야?

**실제 응답**

> 건국대학교 컴퓨터공학과는 논술 최저학력기준이 없습니다.

**검증 결과**

보유 건국대 수시 모집요강 PDF 43페이지에는 논술전형의 **“수능최저학력기준 있음”**이 명시돼 있다. 44페이지의 선발원칙도 최저기준 충족자 중 선발한다고 설명한다.

**판정: 오답**

전형 분류가 비어 문서 검색으로 연결되지 않았고, 일반 답변 경로에서 대학별 사실을 생성했다. 인용 검증은 이 경로에 적용되지 않았다.

### 사례 B. 올바른 모집인원이 최종 답변에서 제외됨 — 5번

**질문 요지**

> 서울대 컴퓨터공학부의 수시·정시 모집인원

| 구분 | 원문 확인 | 최종 응답 |
| --- | --- | --- |
| 수시 | 지역균형 9명, 일반 36명, 기회균형 4명, 합계 49명 | 49명 안내 |
| 정시 | 정원 내 일반전형 36명 | 확인 불가 안내 |

**판정: 부분 충족**

정시 36명은 원문에 존재하고 LLM도 해당 숫자를 생성했다. 그러나 인용문을 원문 그대로 복사하지 않고 “모집단위: 컴퓨터공학부, 정원 내: 36”으로 재작성해 원문 일치 검증에서 탈락했다.

이 사례는 자료 부족보다 **인용 생성 형식과 검증 방식의 불일치**가 답변 누락의 원인이었음을 보여준다.

### 사례 C. 복수 대학 질문의 대상 누락 — 4번

**질문 요지**

> 건국대·서울대·연세대·고려대 수시 전형일정

- 대학 4개는 모두 인식했다.
- 건국대는 서류제출·합격자 발표 일부만 안내했다.
- 서울대는 지역균형전형의 접수·서류 일정만 안내했다.
- 연세대와 고려대는 최종 답변이 보류됐다.

**판정: 부분 충족**

대학 인식과 검색 실행에 성공하더라도, 요청한 모든 대학의 답변이 완성되는 것은 아니었다. 복수 대상 질문은 대상별 충족 여부를 별도로 평가해야 한다.

### 사례 D. 질문 대상 오해와 근거 없는 판단 — 19번

**질문 요지**

> 타 학교 산업공학과를 목표로 물리를 이수하지 않았는데, 건국대 학생부종합 지원에 불리한지와 자유전공학부 지원 가능성

**실제 응답 일부**

> 건국대학교 산업공학과의 학생부 종합 전형에서 물리 과목을 이수하지 않은 경우 불이익이 클 수 있습니다.

**판정: 질문 대상 오해 및 근거 없는 답변**

“타학교 산업공학과 목표”라는 배경을 건국대 산업공학과 지원 질문으로 바꿔 해석했다. 관련 문서를 검색하지 않은 상태에서 물리 미이수의 불이익을 추측했다.

물리 미이수에 불이익이 전혀 없다고 검증한 것은 아니다. 이번 판정은 **해당 응답에 대학별 판단을 뒷받침하는 근거가 없었다는 점**에 따른 것이다.

## 6. 원인 분석

| 원인 | 확인된 현상 | 영향 |
| --- | --- | --- |
| 검색 진입 조건이 제한적 | 수시·정시 등 분류가 비면 대학별 질문도 일반 답변으로 이동 | 자료가 있어도 검색하지 못함 |
| 전형·학과 표현 연결 부족 | KU일반학생, 논술, 자유전공 관련 질문에서 필요한 정보 추출이 부족함 | 검색 대상과 조건을 구성하지 못함 |
| 표·날짜 인용 방식 불일치 | 원문을 재작성한 인용과 숫자 표기 차이가 검증에 영향을 줌 | 유효한 정보까지 탈락 |
| 일반 답변 경로에 검증 미적용 | 11·19번이 문서 근거 없이 생성됨 | 사실 오류와 근거 없는 판단 발생 |
| 상담·탐색 질문 대응 부족 | 대학 비교, 조건에 맞는 전형 탐색을 대부분 거절 | 답변 보류율 증가 |

위 내용은 이번 실행에서 관찰한 원인이다. 각 원인이 전체 오류에 기여한 비중을 독립 실험으로 측정한 것은 아니다.

### 후속 검증 체크리스트

- [ ] 기존 23문항을 동일한 기준으로 재평가한다.
- [ ] 문항별 개선 전·후 답변과 근거 페이지를 함께 비교한다.
- [ ] 동일 질문을 반복 실행해 결과 변동을 확인한다.
- [ ] 표현을 바꾼 신규 문항을 추가해 기존 질문에만 맞춘 개선인지 확인한다.
- [ ] 정답률과 함께 답변 보류율·근거 없는 답변 비율을 측정한다.
- [ ] 일부라도 답한 비율을 완전 정답률과 구분해 보고한다.

## 8. 평가의 한계

1. **표본이 작다.** 사용자 제공 23문항만 평가했으며 전체 입시 질문을 대표한다고 볼 수 없다.
2. **문항당 1회 실행이다.** 생성 모델의 응답 변동성을 측정하지 않았다.
3. **보유 자료 기준이다.** 최신 공식 문서와의 일치 여부를 별도로 검증하지 않았다.
4. **완전 정답률은 질문 해결 기준이다.** 사실 문장만의 정확도, 상담 응답의 유용성과 동일한 지표가 아니다.
5. **답변 보류의 원인은 다양하다.** 자료 부족, 대상 불명확, 검색 실패, 검증 탈락을 하나의 사실 오류로 해석하면 안 된다.
6. **채점은 수동으로 수행했다.** 독립 평가자 간 일치도를 확인하지 않았다.
7. **회귀 테스트와 목적이 다르다.** 기존 테스트 46개 통과는 코드 동작 검증이며, 실제 사용자 질문에 대한 정답률을 보장하지 않는다.

## 9. 종합 의견

현재 우선 과제는 답변을 더 많이 생성하는 것보다 **확인 가능한 질문을 검색에 연결하고, 올바른 근거는 보존하면서 잘못된 판단은 차단하는 것**이다.

검색 연결, 인용 검증, 일반 답변의 근거 확인을 개선한 뒤 동일 문항과 신규 문항으로 다시 평가해야 한다. 이번 수치는 그 개선 효과를 비교하기 위한 기준 결과로 사용한다.
