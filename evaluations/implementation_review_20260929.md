## 보완 과정에서 확인한 문제

중단 전에 저장된 `image_questions_after_20260928.json`에는 23개 결과가 모두 남아 있었다. 서울대 모집인원 구분은 개선됐지만 미대 관련 13·16·17번은 여전히 표와 대상 조건을 잘못 해석했다. 해당 결과를 최종 성능으로 사용하지 않고 오답 차단 조건과 회귀 테스트를 추가했다.

## 검증의 한계

- 테스트 통과율은 실제 질문의 정답률이 아니다.
- 근거 ID와 숫자 검사는 문장의 모든 의미를 증명하지 않는다. 복잡한 표의 단계·열, 지원자 유형과 세부 전형의 적용 범위는 추가 개선이 필요하다.
- 경쟁률·충원·합격 백분위·건물 시설은 현재 모집요강만으로 답하지 못할 수 있다. 임의의 수치나 우열을 생성하지 않도록 처리한다.
- 미술 조건 검색은 보유 대학 자료 중 제한된 후보를 탐색한다. 전국 전형의 완전한 목록을 보장하지 않는다.
- 기존 API 규격을 유지하며, 연도 관련 질문 지원은 확대하지 않았다. 12번은 기존 평가와 동일하게 주요 채점 대상에서 제외한다.

## 실행 결과와 최종 검증

실제 API 실행은 23문항 모두 완료했고 실행 예외는 0건, 생성 호출은 31회였다. NER는 로컬 모델을 사용했다. 이후 두 가지 검증을 추가했다: 모집인원을 요청하지 않은 질문의 인원 문장 차단, 특정 모집단위의 전형방법 질문에서 대상 학과를 밝히지 않은 문장 차단.

마지막 두 검증은 새로운 API 답변을 생성하지 않고, 저장된 NER와 실제 모델 응답을 동일한 검색·답변 경로에 재입력해 확인했다. `image_questions_replay_20260929.json`에 23문항 결과가 있으며 **3번과 18번만 변경**됐다. 이는 실제 API 재실행과 구별되는 회귀 검증이다. 새로운 생성 결과까지 검증한 최종 정답률로 표현하지 않는다.

## 남은 개선 우선순위

1. 영어 환산표·공통 일정·미술 전형의 검색 후보를 정답 페이지와 대조해 누락 원인을 줄인다.
2. 복잡한 표는 모집단위·세부 전형·단계·평가요소·비율을 연결한 구조로 보존한다. 현재 문자열 검사만으로는 충분하지 않다.
3. 실제 모집단위 별칭과 전형 적용 범위를 문서 근거로 연결한다. 잘못된 이름을 임의로 동일시하지 않는다.
4. 보류 문항에 대한 근거 확보 후 동일 평가 기준으로 다시 채점한다. 상담 적절성과 사실 정답률은 분리해 보고한다.
