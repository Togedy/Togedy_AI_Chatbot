## 핵심 결과

비율의 상한·하한과 제외 대상을 놓치던 문제를 수정했다. 질문에 명시한 조건을 표 선택과 생성 답변 검증에 함께 적용하고, 단계가 지정되면 해당 단계의 비율을 확인한다. 세부 전형을 바꾸는 후속 질문에서도 이전에 묻던 항목을 유지한다.

| 새 질문 28개의 조건 해석·표 선택 검사 | 4/28 통과 | 28/28 통과 | 로컬 구성요소 평가 |
| 전체 회귀 테스트 | 기존 검증 106개 | 156개 통과 | 코드의 정상 동작과 오답 차단 검사 |

## 문제와 적용한 수정

| 확인한 문제 | 수정 내용 | 기대 효과 |
| --- | --- | --- |
| ‘이상’만 처리하고 ‘이하·미만·초과’를 무시 | 상한·하한·엄격한 경계·정확한 비율을 구분. %, 퍼센트, 프로 표현 지원 | 60%를 ‘60% 초과’ 조건에 포함하지 않음 |
| 두 비율 조건 중 하나만 적용 | 실기·수능 조건을 함께 검사하고 0~100% 및 합계상 가능한 범위를 확인 | 수능60% 이상·실기40% 이하를 동시에 적용 |
| 제외한 대학·학과를 검색 대상으로 사용 | ‘제외·말고·빼고’를 해석해 검색 대학, 검토된 표와 생성 답변에서 제외 | 사용자가 제외한 후보의 재추천 방지 |
| 명시한 단계 대신 최종 비율 사용 | 1단계·2단계·일괄합산 구분. 여러 단계의 조건 연결이 불명확하면 확인 요청 | 1단계 학생부100%를 최종 실기100%와 혼동하지 않음 |
| 복합 질문에서 검토된 표의 전형방법만 답함 | 표를 직접 반환하기 전에 모든 요청 항목과 대상이 충족되는지 확인 | 모집인원 등 다른 요청의 조용한 누락 방지 |
| 세부 전형과 후속 문맥 누락 | KU자기추천·고른기회 등 인식 보완. 예과·교육과 등 학과명 보존. 전형 변경 시 이전 요청 항목 유지 | ‘KU일반학생은?’을 정시 제출서류 질문으로 이어 처리 |
| 검증 모델의 승인만으로 통과 | 해당 주장이 인용한 근거 ID와 정확한 원문 인용도 요구. 누락·잘못된 ID·재작성 인용은 거절 | 다른 페이지나 허구 인용으로 승인되는 오류 차단 |
| 엄격한 인용 검사로 정상 일정까지 보류 | CSV의 항목명과 날짜가 원문의 같은 행에 연속해 있을 때 직접 추출. 공통 일정표 우선 | 원문 일정의 안정적 제공 |

비율이 기재되지 않은 평가요소를 임의로 0%로 만들지 않는다. ‘실기 없는 전형’은 확인된 실기 유무로 검사하고, 비율 조건은 명시된 평가요소와 수치에 적용한다.

## 실제 동작 예시

| 질문 또는 상황 | 수정 후 처리 |
| --- | --- |
| 실기 60% 이하인 미대 | 검토된 사례 중 실기40%의 건국대 현대미술학과가 조건에 해당. 실기100% 사례는 제외 |
| 수능 60% 초과인 미대 | 수능60% 사례를 포함하지 않음 |
| 수능 60% 이상이고 실기 40% 이하 | 두 조건을 모두 적용 |
| 실기 80% 이상이고 실기 40% 이하 | 모순된 조건을 확인 질문으로 처리 |
| 건대 빼고 수능 60% 이상인 미대 | 건국대를 검색과 표 선택에서 제외 |
| 60% 이상인 미대 | 실기·수능 중 어느 항목인지 확인 요청 |
| 한양대 미대 1단계 실기100% | 최종 단계 실기100%인 사례를 1단계 근거로 사용하지 않음 |
| 이전 질문: 건국대 수시 제출서류 → 후속: KU일반학생은? | 정시로 전환하고 제출서류 요청을 유지 |
| 검증 결과: 승인, 인용은 요약문 | 정확한 원문 인용이 아니므로 거절 |

대학 사례는 프로젝트에 저장된 모집요강 기준이다. 전체 대학 전형 목록이나 현재 최신 학년도의 모집요강으로 확대해 해석하지 않는다.

## 일정 답변의 회귀와 보완

인용 검증을 강화한 중간 실행에서는 검증 모델이 요약문을 인용하거나 일부 문장의 검토를 누락해 건국대·연세대 일정 답변이 보류됐다. 이를 발견해 다음 조건의 직접 추출을 추가했다.

- 항목명과 날짜가 원문의 동일한 행에 연속해 존재해야 한다.
- CSV에만 있거나 원문과 다른 날짜는 사용하지 않는다.
- 같은 페이지에 존재하는 다른 행의 날짜를 바꿔 연결하지 않는다.
- 날짜 열이 여러 개이거나 항목명이 비어 연결을 확정할 수 없으면 생략한다.
- KU자기추천처럼 전형명만 남은 행을 일정 항목으로 취급하지 않는다.
- 세부 전형이 지정되지 않았다면 대학 공통 일정표를 우선한다.

최종 4번 답변에는 네 대학의 일정이 포함됐다. 서울대의 일부 일정과 연세대의 시험·발표 일정까지 모두 완성한 것은 아니다. 표 추출과 모델 검증을 통과한 범위만 제공한다.

## 남은 한계와 다음 작업

- 정확한 인용은 원문 존재를 증명하지만 문장의 의미까지 완전히 보장하지 않는다. 모델이 원문의 조건을 잘못 해석할 가능성이 남아 있다.
- 검토된 구조화 자료의 대학·전형 범위는 이전과 동일하다. 전국 전형을 찾으려면 검토 자료를 확대해야 한다.
- 새 28문항의 실제 모델 답변은 이번에 외부 전송하지 않았다. 수정에 사용하지 않은 별도 문항으로 NER·검색·최종 답변까지 평가해야 전체 성능을 판단할 수 있다.
- 경쟁률·충원·합격 백분위·시설은 공식 입시결과나 캠퍼스 자료 확보가 필요하다.
- 여러 차례 이어지는 긴 대화와 모든 자연어 조건 표현을 포괄한 평가도 추가로 필요하다.
